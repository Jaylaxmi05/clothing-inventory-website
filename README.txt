THREADSTOCK — UPDATED WITH DEMO LOGIN/SIGNUP

FILES
- index.html: login/signup screen and existing dashboard structure
- style.css: existing styling plus login/signup styling
- auth.js: localStorage demo authentication and logout
- script.js: existing inventory, billing, sales and browser storage logic

RUN
1. Keep all four files in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. Select Sign up, create an account, then log in.
4. After login, the existing ThreadStock dashboard appears.
5. Use Log out in the left sidebar to return to the login screen.

DEMO AUTHENTICATION NOTE
This is only a frontend demonstration. Passwords are stored in localStorage
as plain text and are not secure. Accounts exist only in the same browser.
Do not use real passwords or sensitive information. For a real website,
use a backend and a proper authentication provider.
